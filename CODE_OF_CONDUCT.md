# Code of Conduct

This project adopts the spirit and core text of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (CC BY 4.0), in a shortened form.

## Our pledge

We want participation to be a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive; assume good faith.
- Give and accept technical criticism graciously. Critique code and designs, not people.
- Be honest about limits and uncertainty, especially in security claims.
- Respect people's privacy: do not share anyone's personal information or private communications.

## Unacceptable behaviour

- Harassment, insults, discrimination, threats, or personal attacks.
- Sexualized language or imagery, and unwelcome advances.
- Publishing others' private information without permission.
- Sustained disruption of discussions.

## Enforcement

Maintainers may edit or remove comments, commits, issues and other contributions that violate this Code, and may temporarily or permanently restrict participation. Report conduct problems to the maintainers by contacting the repository owner through GitHub (for sensitive reports, use a private channel offered by GitHub rather than a public issue). Reports are handled confidentially. Security vulnerabilities follow [SECURITY.md](SECURITY.md), not this document.
